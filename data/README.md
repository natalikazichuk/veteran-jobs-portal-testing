# QA Data & Working Workbook

The source workbook QA_VJP.xlsx is a large working file containing 28 sheets, including role-specific Test Cases, Bug Report, Test Summary, Testing Scenarios, Smoke Tests, UAT journeys, Test Coverage Summary and test data.

A public-safe sanitized copy was prepared from that workbook. Test emails and phone numbers were replaced with placeholders, passwords were removed, and private Google Docs/Sheets/Postman links were omitted.

The repository uses Markdown for the most useful portfolio-facing suites so recruiters can read them directly in GitHub.

The complete sanitized workbook is available as a downloadable artifact in the chat, rather than publishing a large binary copy in the repository.
