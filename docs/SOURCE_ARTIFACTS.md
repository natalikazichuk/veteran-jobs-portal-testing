# Source Artifacts

The QA portfolio was prepared from the following project materials supplied for this project:

- VJP Test Plan
- User Stories and Testing Scenarios
- VJP VTC / test cases
- Functional testing checklist
- Veteran registration checklist
- QA Bug Report
- Selected screenshots/evidence

The GitHub repository contains the cleaned recruiter-friendly Markdown/CSV presentation. Original PDF/DOCX evidence remains available in the prepared portfolio package.

The portfolio does not invent missing severity, priority, dates or requirements. Observations that are not supported by the supplied requirements are marked as follow-up items rather than defects.
