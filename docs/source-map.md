# Source Map

## Files used
The repository was reorganized from the uploaded working materials:
- QA_VJP.xlsx — main working workbook with role suites, scenarios, execution results, metrics and defect register.
- QA_VJP.pdf — compiled QA evidence/report with test plan, scenarios, smoke tests, coverage and defect summaries.
- VJP Чек-лист.pdf — Veteran ↔ Recruiter interaction checklist and execution observations.
- Check List 1 Реєстрація як Ветеран.pdf — focused Veteran registration execution.
- VJP Test Cases.pdf — English role-oriented test cases.

## Privacy and publication
The public repository does not reproduce raw test credentials or private Google Drive/Docs/Sheets/Postman links from the working materials.

The repository intentionally uses a curated portfolio representation rather than uploading the raw working PDFs.
